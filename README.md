# 🏨 AURELIA — Boutique Hotel

A premium, responsive boutique hotel website demo built with **HTML, CSS and JavaScript**.

## 🚀 Live Demo

After deploying with GitHub Pages, add your live URL here:

## ✨ Features
- Responsive mobile, tablet, desktop and landscape layouts
- Boutique hotel hero section
- Room showcase and pricing
- Experience section
- Special offer section
- Reservation request form
- Scroll/reveal animations
- Toast confirmation UI
- PWA manifest and service worker

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
- PWA APIs

## 📁 Structure
```text
├── index.html
├── style.css
├── script.js
├── manifest.json
├── service-worker.js
└── README.md
```

## 📌 Note
This is a **demo/portfolio website concept**. The reservation form is front-end only and does not process real bookings or payments.
